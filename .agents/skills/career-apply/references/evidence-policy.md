# Evidence/writing

[AGENTS](../../../../AGENTS.md) governs sources, bullet fact IDs and numbers. Direct means explicit support; transferable means adjacent experience with clear scope; gap means unsupported. Preserve titles/dates and exact metric values/units/qualifiers; manually verify summary/project names. Resolve skills warnings, checking supporting facts outside the selection too.

STAR: situation→goal/constraint→decision/action→result; outcome-first before tools, only when supported. Separate independent projects/publications from employment. Retain supported differentiators beyond JD keywords.

Both variants use canonical evidence. An optional stretched variant changes positioning only, not skills or study claims. Record differences, fact IDs and wording limits in a review note; keep proposed learning outside resumes. Disclose material gaps.
